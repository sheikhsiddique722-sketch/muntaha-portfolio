Overview

Project Overview

This portfolio website was conceived and built as a flagship showcase for generative AI capabilities and creative direction. Every detail — from the custom cursor animations to the scroll-triggered reveals — was crafted to communicate a distinct personal brand that merges technical precision with aesthetic refinement.

The design philosophy centres on restraint and elegance: a warm, neutral palette punctuated by gold accents, editorial typography drawn from Cormorant Garamond, and micro-interactions that reward attentive visitors. The result is a digital presence that feels both contemporary and timeless.

Built entirely with semantic HTML, CSS custom properties, and vanilla JavaScript — no frameworks, no bloat — the site loads instantly and performs flawlessly across all devices.

Highlights

Key Features

  • Custom SVG cursor with smooth lag-follow ring effect that scales on interactive elements
  • Scroll-triggered reveal animations using IntersectionObserver for buttery-smooth entrance transitions
  • Animated skill bars that fill progressively when each card enters the viewport
  • Floating conic-gradient orb on the hero card with continuous CSS spin animation
  • Sticky frosted-glass navigation bar with scroll-state border transition
  • Fully responsive layout with a slide-in mobile menu overlay for small screens
  • Contact form with client-side success state — no page reload required
  • Warm editorial colour palette using CSS custom properties for effortless theming
  • Radial-gradient ambient orbs in the hero section with looping float animation
  • Zero external JavaScript dependencies — entirely vanilla for maximum performance
